# A Sidon set constant

## Description of constant

$C_{5a}$ is the smallest constant such that Sidon sets in $\\{1,\dots,N\\}$ have cardinality $N^{1/2} + (C_{5a} + o(1))N^{1/4}$.

| $0.9435$ | [HZ26] | $\gamma\_0 = 0.94349\dots < 0.9435$, by a vector-valued smoothing method combining several discrete smoothing kernels with boundary weights. Stated against the published $0.98183$ of [CHO25]; the unpublished $0.97633$ above is not accounted for there. |
| $0.94304$ | [COT26] | Corollary 1.2: a Sidon set $\mathcal{A}\subseteq[1,N]$ with $k\ge 483$ elements satisfies $k \le N^{1/2} + 0.94304\,N^{1/4} + 0.44466$, equivalently $\mathrm{diam}(\mathcal{A}) \ge k^2 - 1.88607\,k^{3/2}$. The fully explicit bound valid for every $k \ge 1$ is $\lvert\mathcal{A}\rvert \le N^{1/2} + 0.945\,N^{1/4} + 0.447$; since $C\_{5a}$ is asymptotic, the large-$k$ constant is the one recorded. |

## Additional comments and links

- **On the constant attributed to [CHO25].** [COT26, §1] cites that paper as giving $\mathrm{diam}(\mathcal{A}) \ge k^2 - 1.98183\,k^{3/2} - O(k)$, which would correspond to $C\_{5a} \le 0.990915$. The figure recorded above is [CHO25]'s own: its abstract states $b \le 1.96365$ and, equivalently, $n^{1/2} + 0.98183\,n^{1/4} + O(1)$, and $1.96365/2 = 0.981825$. [HZ26] also describes $0.98183$ as the previously published coefficient. The $1.98183$ appears to be a slip in [COT26]; nothing else depends on it.
- This is part of [Erdős problem #30](https://www.erdosproblems.com/30).
- A survey of the literature can be found at [OBO4].
